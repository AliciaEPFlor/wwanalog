WWAnalog — configuração PostgreSQL

1. Dentro de database, copie config.local.example.php para config.local.php.
2. No arquivo config.local.php, preencha localmente a senha atual do PostgreSQL.
3. Inicie o servidor PHP na raiz wwanalog_fixed.
4. Abra http://localhost:8001/database/teste_conexao.php (ajuste a porta se necessário).
5. Depois do teste, apague database/teste_conexao.php.

A conexão PDO está disponível pela função db() definida em includes/config.php.
O site ainda usa database/data.php como armazenamento de dados das páginas. Esta
etapa não altera tabelas nem migra dados existentes; isso exige inspeção prévia do
esquema real no pgAdmin.

Nunca compartilhe config.local.php nem publique senhas. Não use a senha desejada
123456 como senha administrativa de produção; é muito fraca. Primeiro teste com a
senha atual que funciona.


ARQUITETURA ESCALÁVEL (base inicial)
Consulte deploy/README-ESCALABILIDADE.md. O docker-compose.yml inicia NGINX + quatro instâncias PHP-FPM e conecta ao PostgreSQL EXISTENTE via variáveis de ambiente. Ele não cria nem modifica o banco. A aplicação ainda precisa migrar dados de database/data.php para tabelas reais antes de se considerar totalmente integrada ao PostgreSQL.
